# Sticker

Sticker is a new neural network architecture with shallow mixture-of-experts (MoE) consensus based on biological principles.

The name comes from the phrase 'scalping on tickers', related to the first performed financial market scalping test showcasing the model.

As a continual learning model, Sticker outperforms all neural network models in accuracy, inference and update latency, and shows the best throughput record among the baselines tested, at orders of magnitude higher efficiency than traditional neural networks, demonstrating a new state-of-the-art Pareto frontier.

Test details, configuration and comparison are available in [`mid_price_movement/`](mid_price_movement/)
