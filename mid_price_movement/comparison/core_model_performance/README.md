# Core Model Performance

The comparison evaluates model performance in a noisy stochastic market environment, predicting whether the mid-price will move up (+1) or down (-1) across immediate future horizons, and related core performance areas.

Metrics are available in [`test_metrics.json`](test_metrics.json) and [`test_rank.csv`](test_rank.csv) (ranked models are sorted by non-zero directional accuracy at horizon 1).
